## What it does and the pages in general

SmartSeat has 3 user profiles
- Student
- Lecturer
- Admin

## Student
The student user page is simple. You can book seats and ask Ai which seat is available and suitable for you

## Lecturer 
The lecturer can book a room for their class or see who booked the seat. They can also see the heatmap of the taken seats

## Admin
The admin can view the statistical history and analytics in general.
